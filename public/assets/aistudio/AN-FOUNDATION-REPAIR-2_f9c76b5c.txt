1) إزالة Vite mock API بالكامل
──────────────────────────────────────────────────────────────────
أعد كتابة vite.config.ts بحيث:
- plugins: react + tailwind فقط — **احذف devApiPlugin بالكامل**
- لا Map جلسات، لا شركات وهمية، لا admin/AdminPass123!
- أضف proxy لكل /api إلى الخادم الحقيقي:

```ts
server: {
  port: 3000,
  host: '0.0.0.0',
  proxy: {
    '/api': {
      target: process.env.API_PROXY_TARGET || 'http://127.0.0.1:3001',
      changeOrigin: true,
    },
  },
},
```

في package.json:
- "dev:api": "tsx server.ts" مع PORT=3001 في السكربت أو .env.example
- "dev:web": "vite"
- "dev": أبقِه واضحًا — إما concurrently إن وُجدت الحزمة، أو وثّق أن يجب تشغيل dev:api و dev:web
  يُفضّل إضافة concurrently كـ devDependency و:
  "dev": "concurrently -k \"npm:dev:api\" \"npm:dev:web\""
  مع PORT=3001 للـ API في dev:api

.env.example:
```
PORT=3001
API_PROXY_TARGET=http://127.0.0.1:3001
# لا تضع كلمات مرور افتراضية في أي ملف كود
```

4) CORS / Rate limit / SSL / CSP
──────────────────────────────────────────────────────────────────
### corsConfig
- لا تستخدم includes('localhost') بشكل يمرر evil-localhost.com
- طابق أصلًا بدقة أو قائمة بادئات آمنة (http://localhost: و http://127.0.0.1:)
- لا تسمح بنمط .run.app عام لكل التطبيقات؛ اطلب origins صريحة في CORS_ORIGINS

### rate limit على login
- عدّ المحاولات **الفاشلة** فقط (أو وثّق إن عدّ الكل)
- TTL تنظيف دوري لمفاتيح Map القديمة

### SSL
- إذا NODE_ENV=production و DATABASE_SSL=disable دون ALLOW_INSECURE_DB_SSL=1 → ارفض الاتصال / ارمه خطأ عند connect

### helmet
- فعّل CSP مضبوطًا minimal مناسب لـ SPA (defaultSrc 'self'؛ scriptSrc 'self'؛ …) بدل contentSecurityPolicy: false
- إن تعارض مع Vite في dev فقط، خفّف في development وليس production
