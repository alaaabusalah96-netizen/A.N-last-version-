الخطوة 2 — تنفيذ الملفات الصغيرة (المسؤوليات)
──────────────────────────────────────────────────────────────────

### passwordHash.ts
- hashPassword(plain): Promise<string>
- verifyPassword(plain, hash): Promise<boolean>

### userStore.ts
- interface User { id, username, passwordHash, role: 'platform_admin' | 'user', companyId?: string | null, createdAt }
- createUser, findByUsername, listUsers (dev)
- تخزين Map في الذاكرة V1

### sessionStore.ts
- createSession(userId): { id, userId, expiresAt }
- getSession(id), revokeSession(id), revokeAllForUser(userId)
- TTL من env SESSION_TTL_HOURS افتراضي 12

### authService.ts
- login(username, password) → session أو خطأ
- logout(sessionId)
- bootstrapPlatformAdminFromEnv():
  - يقرأ PLATFORM_ADMIN_USERNAME + PLATFORM_ADMIN_PASSWORD من env
  - إن ناقصين: تخطَّ بهدوء
  - إن موجودين ولا يوجد المستخدم: أنشئه role=platform_admin
  - لا تسجّل كلمة المرور في اللوج

### authMiddleware.ts
- يقرأ cookie اسمها an_session (أو من Authorization لاحقًا)
- يرفق req.user أو يرفض 401

### authRoutes.ts
- POST /api/auth/login { username, password }
- POST /api/auth/logout
- GET /api/auth/me
- cookie: httpOnly, sameSite=lax, secure إن production, path=/

### server.ts
- cookieParser()
- استدع bootstrap عند الإقلاع
- app.use('/api/auth', authRoutes)
- لا تضع منطق login داخل server.ts
- أبقِ /api/health و /api/ready

### الواجهة
- LoginForm: حقول + استدعاء /api/auth/login بـ credentials: 'include'
- بعد نجاح: عرض «مسجّل» + زر خروج + استدعاء /api/auth/me
- لا Firebase

### .env.example
```
PLATFORM_ADMIN_USERNAME=
PLATFORM_ADMIN_PASSWORD=
SESSION_TTL_HOURS=12
SESSION_COOKIE_NAME=an_session
```
