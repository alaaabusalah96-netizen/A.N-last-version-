## الهدف
تأسيس طبقة بيانات مستقلة عن منطق الأعمال:
- Database Engine Interface
- PostgreSQL Adapter (هيكل + تنفيذ أساسي قابل للاتصال عند وجود DATABASE_URL)
- Connection Registry
- Tenant-to-Database Resolver
- استراتيجية عزل tenant على مستوى التطبيق (companyId في كل استعلام/سياق)
- تحديث /api/ready ليعكس حالة الإعداد دون كسر التشغيل إن لم تُضبط DATABASE_URL

## خارج النطاق (ممنوع في هذه الحزمة)
- P02b محرك ثانٍ | P02c backup/ترحيل كامل | P02d offline كامل
- P03 هوية/جلسات كاملة
- وحدات محاسبة/مخازن
- Firebase بأي شكل
- ترحيلات إنتاجية على بيانات حقيقية دون موافقة

## قواعد
1) لا تسريب أنواع/SQL خاصة بـ Postgres إلى مجلد domain أو application — فقط infrastructure/db
2) إن غابت DATABASE_URL: النظام يعمل؛ ready يوضح database: not_configured أو configured=false
3) إن وُجدت DATABASE_URL: اختبار اتصال اختياري آمن (SELECT 1) دون إنشاء جداول أعمال
4) آخر الرد: كتلة RESULTS فقط
5) لا تبدأ P02b/P03 تلقائيًا

الخطوة 2 — العقود (Interfaces)
──────────────────────────────────────────────────────────────────

### src/server/db/types.ts
عرّف على الأقل:
- type DatabaseMode = 'central' | 'per_company' | 'on_prem' | 'hybrid'
- interface TenantDbRef { companyId: string; mode: DatabaseMode; connectionKey: string }
- interface QueryResult<T = unknown> { rows: T[]; rowCount: number }
- interface DbExecutor {
  query<T = unknown>(sql: string, params?: unknown[]): Promise<QueryResult<T>>
  withTransaction<T>(fn: (ex: DbExecutor) => Promise<T>): Promise<T>
  health(): Promise<{ ok: boolean; detail?: string }>
  close(): Promise<void>
}

### src/server/db/DatabaseEngine.ts
- interface DatabaseEngine {
  readonly id: string // e.g. 'postgresql'
  connect(config: Record<string, string>): Promise<DbExecutor>
  }

### src/server/db/ConnectionRegistry.ts
- class/memory registry: map connectionKey → config (من env)
- methods: register, get, listKeys, has
- لا تطبع كلمات السر في logs

### src/server/db/TenantDatabaseResolver.ts
- resolve(companyId: string): TenantDbRef
- في V1 الافتراضي: mode='central' و connectionKey='default'
- اقرأ اختياريًا من env: DB_MODE=central
- لا تخلط شركات على مفاتيح مختلفة بالخطأ — وثّق السلوك

### src/server/db/adapters/PostgresqlAdapter.ts
- implements DatabaseEngine id='postgresql'
- استخدم حزمة `pg` (أضفها لـ package.json dependencies)
- connect يقرأ connectionString من config.connectionString أو DATABASE_URL
- health: SELECT 1
- withTransaction: BEGIN/COMMIT/ROLLBACK
- إن فشل البناء بدون pg types: أضف @types/pg dev

### src/server/db/index.ts
- export الواجهات + getDefaultExecutor(): Promise<DbExecutor | null>
  - إن لم توجد DATABASE_URL أرجع null
  - وإلا connect عبر PostgresqlAdapter + Registry key default
