### src/server/rbac/rbacService.ts
عدّل hasPermission:
- platform_admin: كما هو (صلاحيات الدور)
- إذا لم يُمرَّر companyId:
  - اسمح إذا كان لدى المستخدم **أي** عضوية نشطة دورها يمنح permission
    (اجمع memberships عبر listByUser)
  - وإلا false
- إذا مُرِّر companyId: عضوية تلك الشركة + صلاحية الدور

### src/server/routes/companyRoutes.ts
- GET `/`: بعد requireAuth فقط (أو requirePermission بعد إصلاح rbac)
  المنطق يبقى: platform → list الكل؛ غير ذلك → عضوياته
- تأكد أن company_user بعد الإصلاح لا يحصل 403 قبل الوصول للمنطق

### scripts/verifyFixRbacCompanies.ts (سلوكي على المخازن الذاكرة)
- أنشئ مستخدمين وعضويات في الذاكرة عبر الاستدعاءات المباشرة لـ stores (بدون HTTP إن صعب)
- أو استورد rbacService واثبت:
  - platform_admin + company:read → true
  - user بعضوية company_admin + company:read بدون companyId → true
  - user بلا عضوية → false
  - user عضوية شركة A + فحص companyId=B → false

الإصلاح 2 — DB executor + resolver + registry + SSL
──────────────────────────────────────────────────────────────────
### src/server/db/ConnectionRegistry.ts
- أضف getPublic(key) يعيد config بدون password/connectionString الكامل (اخفِ أسرارًا)
- احتفظ get(key) داخلي للاستخدام من طبقة db فقط — وثّق «لا تستخدم في routes»
- map من key → { config, executor? } اختياري لتعدد الاتصالات

### src/server/db/index.ts
- أضف getExecutorForCompany(companyId: string): Promise<DbExecutor | null>
  1) ref = defaultResolver.resolve(companyId)
  2) config = registry.get(ref.connectionKey) أو default من DATABASE_URL
  3) cache executors per connectionKey
- getDefaultExecutor يبقى للـ central default
- لا تسجّل connectionString في console

### src/server/db/adapters/PostgresqlAdapter.ts
SSL:
```
ssl: (() => {
  if (process.env.DATABASE_SSL === 'disable') return undefined;
  if (process.env.NODE_ENV === 'production' || process.env.DATABASE_SSL === 'require') {
    return { rejectUnauthorized: process.env.DATABASE_SSL_REJECT_UNAUTHORIZED !== 'false' };
  }
  return undefined;
})(),
```
الافتراضي في production: rejectUnauthorized **true** (عكس السلوك الخطر السابق)
