PHASE 1 — MIGRATIONS
──────────────────────────────────────────────────────────────────
Create database/migrations/ (SQL files, small):

001_platform_users.sql
- id UUID PK DEFAULT gen_random_uuid()
- username UNIQUE NOT NULL, password_hash NOT NULL
- platform_role VARCHAR, is_active BOOLEAN DEFAULT true
- created_at, updated_at, last_login_at
- extension pgcrypto if needed

002_companies.sql
- id UUID PK, code UNIQUE, name_ar, name_en nullable
- is_active, database_mode DEFAULT 'central', database_connection_key nullable
- created_by FK platform_users nullable, timestamps

003_company_memberships.sql
- id UUID, user_id FK, company_id FK, role_code, is_active DEFAULT true
- UNIQUE(user_id, company_id), indexes

004_user_sessions.sql
- id UUID, user_id FK, token_hash UNIQUE NOT NULL
- expires_at, revoked_at nullable, created_at, last_seen_at
- ip_address, user_agent optional

005_schema_migrations.sql (version tracking)
- id / version text PK, applied_at

Optional later (not required to finish CORE): audit_logs can wait for AUTH-SECURITY package unless trivial.
