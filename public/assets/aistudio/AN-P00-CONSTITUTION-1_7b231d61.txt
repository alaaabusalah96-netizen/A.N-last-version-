## قرارات معتمدة (إلزامية — لا تخالفها)
| الموضوع | القرار |
|--------|--------|
| المحرك المرجعي V1 | PostgreSQL |
| محركات أخرى | Adapters لاحقًا؛ كل محرك يُختبر منفردًا قبل إعلان الدعم |
| قاعدة محلية للشركة | مدعومة كنمط On-Premises (اتصال قاعدة الشركة) |
| تشغيل كامل دون إنترنت | مسار نشر مستقل — غير موعود في V1 |
| نقل شركة بين قواعد | ترحيل مضبوط (تحقق + تدقيق + رجوع) وليس زر إعداد |
| من يختار محرك DB؟ | مسؤول المنصة/النشر فقط |
| البنية | Modular Monolith |
| Firebase / Firestore / Firebase Auth | ممنوع نهائيًا (لا مؤقت ولا fallback) |
| المشاريع السابقة | مراجع فنية فقط — لا تشغيل عليها ولا نسخ شجرتها |
| فصل المفهومين | دعم محرك DB ≠ تشغيل النظام بالكامل offline |
