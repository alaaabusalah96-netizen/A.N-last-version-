# النظرة العامة المعمارية (Architecture Overview)

## 1. النمط المعماري العام (Modular Monolith)
يعتمد النظام نمط **Modular Monolith** (الكتلة الواحدة المجزأة لوحدات نمطية مستقلة).
- تم اختيار هذا النمط لتحقيق أعلى درجات الاتساق والتماسك، وتبسيط النشر والصيانة، وإدارة المعاملات المالية والمخزنية المتشابكة بكفاءة دون تعقيدات الشبكات الموزعة.
- **حظر Microservices في V1**: يُمنع تمامًا تشتيت النظام إلى خدمات مصغرة (Microservices) في الإصدار الأول؛ حيث أن تكلفة التعقيد التشغيلي وشبكات الاتصال وتوزيع المعاملات (Distributed Transactions) لا تخدم أهداف مرحلة الإطلاق والاستقرار.

## 2. طبقات النظام (Architectural Layers)
تتبع المنصة مبادئ التصميم النظيف (Clean Architecture / Hexagonal Architecture) مع فصل صارم بين الطبقات:

### أ. طبقة العرض (Presentation Layer)
- واجهة مستخدم حديثة وسريعة مبنية باستخدام **React + TypeScript**.
- تواصل مع الخادم عبر واجهات برمجة تطبيقات واضحة ومتسقة (**REST API** موثقة بمعايير **OpenAPI / Swagger**).
- لا تحتوي طبقة العرض على أي منطق تجاري أو قرارات مالية؛ يقتصر دورها على العرض وإرسال الأحداث والتحقق السطحي من المدخلات للراحة وسرعة الاستجابة.

### ب. طبقة التطبيق (Application Layer)
- مبنية باستخدام **Node.js + TypeScript**.
- مسؤولة عن تنسيق حالات الاستخدام (Use Cases / Application Services)، وإدارة سياق الجلسات، وسياق المستأجر (Tenant Context).
- تنفيذ ضوابط الصلاحيات، وإدارة حدود المعاملات (Transaction Boundaries)، وتوجيه العمليات بين الوحدات.

### ج. طبقة النطاق التجاري (Domain Layer)
- تحتوي على المنطق التجاري الصافي (Business Logic & Domain Rules).
- كيانات النطاق (Entities)، كائنات القيمة (Value Objects)، ومحددات العمليات المحاسبية والمخزنية.
- مستقلة تمامًا عن تفاصيل أطر العمل (Framework-agnostic) وقواعد البيانات وطرق العرض.

### د. طبقة البنية التحتية (Infrastructure Layer)
- توفر التطبيقات العملية للواجهات (Interface Implementations): محولات قواعد البيانات (Database Adapters)، بوابات التخزين، سجل الاتصالات (Connection Registry)، والخدمات الخارجية.
- توفر المرونة لعزل تفاصيل التخزين والاتصال عن قلب النظام.

## 3. حزمة التقنيات المعتمدة (Technology Stack)
- **الواجهة الأمامية**: React + TypeScript.
- **الخادم / واجهات التطبيقات**: Node.js + TypeScript.
- **التواصل**: RESTful APIs موثقة بـ OpenAPI v3.
- **قواعد البيانات**: محرك مرجعي PostgreSQL عبر مزودات بيانات محايدة (Engine-Agnostic Database Adapters).
