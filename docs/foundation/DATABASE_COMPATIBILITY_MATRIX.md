# مصفوفة توافق قواعد البيانات (Database Compatibility Matrix)

## 1. جدول المقارنة المعماري لمحركات قواعد البيانات

| محرك قاعدة البيانات | دعم المعاملات الذرية (ACID) | معالجة بيانات JSON | استراتيجيات القفل والنزاع (Locking & Concurrency) | أمان مستوى السجل (RLS / Tenant Isolation) | أدوات الترحيل المعتمدة (Schema Migration) | النسخ الاحتياطي والاستعادة (Backup & Restore) | حالة الدعم الرسمية |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **PostgreSQL** | كامل (Full ACID, MVCC متقدم) | ممتاز وعالي الأداء (JSONB الفهرس عبر GIN) | قفل دقيق للصفوف (Row-level Locks, Advisory Locks) | مدعوم أصليًا عبر Row-Level Security (RLS) | DDL في المعاملات مع أدوات قياسية | أدوات أصلية مستقرة (pg_dump, WAL, PITR) | **المحرك المرجعي المستهدف في V1** |
| **MySQL (8.0+)** | مدعوم عبر InnoDB | جيد (Native JSON نوع وخصائص) | قفل صفوف InnoDB وقفل القراءات المتسقة | يتطلب تطبيق شروط استعلام إجبارية أو Views | مدعوم جزئيًا (بعض عمليات DDL لا تراجع لها) | mysqldump, Binary Logs | مخطط له كـ Adapter مستقبلي (غير معتمد في V1) |
| **SQL Server** | كامل ومتطور | مدعوم (JSON Functions & Paths) | قفل صفوف وصفحات وSnapshot Isolation | مدعوم أصليًا عبر Row-Level Security | مدعوم عبر سكربتات ترحيل مؤسسية | Native SQL Backups, Transaction Logs | مخطط له كـ Adapter للمؤسسات (غير معتمد في V1) |
| **Oracle** | كامل ومؤسسي | مدعوم (JSON DataType & Indexing) | متعدد الإصدارات ومتقدم للغاية | مدعوم عبر Virtual Private Database (VPD) | ترحيل معقد يتطلب تحكم مؤسسي | RMAN, Datapump | خيار مؤسسي محتمل في مراحل لاحقة (غير معتمد في V1) |
| **SQLite** | كامل للقواعد الفردية | مدعوم (JSON1 Extension) | قفل ملف كامل للكتابة (محدود للنزاع العالي) | عبر فلترة التطبيق فقط (لا RLS أصلي) | دعم محدود لتعديل الأعمدة والقيود | نسخ الملف المباشر (Online Backup API) | مخصص للتجارب والتطوير المحلي الصغير (غير معتمد لـ Production V1) |

## 2. سياسة إعلان الدعم الصارمة
- **حظر إعلان الدعم المسبق**: لا يُعلن الدعم الرسمي لأي محرك قاعدة بيانات بخلاف **PostgreSQL** قبل اجتياز حزمة الاختبارات المعيارية الكاملة للمحرك الجديد.
- يجب أن يجتاز أي محرك مقترح متطلبات:
  1. اختبارات المعاملات المعقدة ومصيدة التراجع (Rollback Integration Tests).
  2. اختبارات عزل المستأجرين والتأكد من عدم حدوث تسريب في الاستعلامات المتوازية.
  3. اختبارات ترحيل المخططات (Migrations) التلقائية والتراجعية.
  4. اختبارات الأداء واستقرار تجمعات الاتصال (Connection Pooling Stability).
