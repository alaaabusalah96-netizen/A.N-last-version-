# دستور المنتج (Product Constitution)

## 1. الهوية والنشأة
هذا النظام هو **منتج رقمي جديد ومستقل تمامًا** لبناء منصة تخطيط موارد المؤسسات (ERP) بمعايير قياسية هندسية حديثة.
- أي كود أو نماذج أو مشاريع سابقة تُعد **مراجع فنية ومصدر استلهام مفاهيمي فقط**.
- يُحظر قطعيًا التشغيل المباشر لأي مشروع قديم، أو نسخ هياكل الكود القديمة، أو افتراض أي اعتماديات سابقة.
- التأسيس يبدأ من الصفر وفق معمارية برمجية واضحة ومستدامة.

## 2. المبادئ الحاكمة الأساسية (Core Tenets)

### أ. الأمان كأولوية قصوى غير قابلة للمساومة (Security by Design)
- الأمان ليس طبقة إضافية بل أساس في كل قرار معماري وبرمجي.
- التحقق الصارم من الهوية والصلاحيات يتم دومًا في الـ Backend ولا يُكتفى بالتحقق في واجهة المستخدم.
- مبدأ الحد الأدنى من الامتيازات (Least Privilege) مطبق على كافة المستخدمين والخدمات والمفاتيح.

### ب. العزل التام للشركات والمستأجرين (Strict Tenant Isolation)
- النظام متعدد الشركات والمستأجرين (Multi-Tenant).
- عزل بيانات كل شركة عزلًا منطقيًا وفيزيائيًا تامًا، مع منع أي تسريب للبيانات بين الشركات تحت أي ظرف من الظروف.
- كل استعلام أو عملية تخزين أو تدقيق يجب أن ترتبط بسياق الشركة المعتمد (`Tenant Context`).

### ج. قاعدة البيانات كالمصدر الأوحد للحقيقة (Database as Single Source of Truth)
- قاعدة البيانات العلائقية (Relational Database) هي المرجع النهائي الوحيد لصحة البيانات والمعاملات المحاسبية والمخزنية.
- ضمان التماسك والمعاملات الذرية (ACID Compliance) في كافة العمليات المالية والتنفيذية.
- منع حفظ الحالات الحساسة في الذاكرة المؤقتة أو التخزين المؤقت دون تثبيتها في قاعدة البيانات.

### د. حظر تقنيات Firebase حظرًا تامًا ومطلقًا
- يُحظر حظرًا قاطعًا استخدام Firebase بكافة أشكاله ومنتجاته:
  - لا Firestore.
  - لا Firebase Authentication.
  - لا Firebase Storage أو Realtime Database أو Cloud Functions الخاصة بـ Firebase.
- لا يُسمح بـ Firebase حتى كحل مؤقت، أو بديل احتياطي (Fallback)، أو أداة تطوير أولية.
- الهوية وإدارة الجلسات تُدار عبر حل محلي مستقل ذو سيادة داخلية للمنصة.

## 3. حجية الدستور وسلطته المرجعية
- هذه الوثيقة تمثل **أعلى مرجع تشريعي وتوجيهي** لكافة القرارات الهندسية والتصميمية في المشروع.
- في حال نشوء أي تعارض بين أي متطلب أو رغبة تطويرية وبين نصوص هذا الدستور:
  1. يتم إيقاف التنفيذ فورًا.
  2. يُسجّل التعارض رسميًا في سجل النتائج ومراجعات المعمارية.
  3. لا يتم تجاوز الدستور إلا بتعديل دستوري صريح وموثق ومعتمد بشريًا.
