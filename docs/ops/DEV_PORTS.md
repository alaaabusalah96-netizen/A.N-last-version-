# دليل منافذ التطوير واختبار المتصفح (Dev Ports & E2E Smoke)

## منافذ التطوير المعتمدة في المشروع

| الخدمة | الأمر | المنفذ | الوصف |
|---|---|---|---|
| **واجهة الويب (Vite)** | `npm run dev:web` | **`:3000`** | يخدم واجهة React على `http://127.0.0.1:3000` (أو `localhost:3000`) ويمرر طلبات `/api/*` تلقائياً إلى `API_PROXY_TARGET` (`http://127.0.0.1:3001`). |
| **خادم الـ API (Express)** | `npm run dev:api` | **`:3001`** | يشغّل `tsx server.ts` مع `PORT=3001` و`APP_PREVIEW_MODE=true`. |
| **تشغيل التطوير الكامل** | `npm run dev` | **`:3000` + `:3001`** | يشغّل `dev:web` و`dev:api` معاً عبر `concurrently`. |
| **معاينة الإنتاج المبنية** | `npm run build && npm start` | **`:3000`** | يشغّل `dist/server.cjs` ليخدم حزمة `dist/` المبنية وواجهات `/api/*` معاً على `PORT` (الافتراضي `3000`). |

---

## قاعدة مهمة لاختبارات المتصفح والتخطيط (`Layout` و `E2E`)

- **`npm run dev` يشغّل `web` (`:3000`) + `api` (`:3001`) معاً.**
- **لا تشغّل خادم الـ API وحده على المنفذ `3000` عند تشغيل اختبارات الواجهة أو التخطيط أو Playwright E2E**، لأن تشغيل `server.ts` وحده على `3000` بدون `Vite` أو بناء `dist/` لا يخدم تطبيق الواجهة بالطريقة التفاعلية الصحيحة لوضع التطوير.

## تشغيل اختبار الدخان بالمتصفح (`test:e2e-smoke`)

يستخدم `npm run test:e2e-smoke` ملف الإعداد `playwright.config.ts` والاختبار `e2e/smoke.spec.ts` لتنفيذ رحلة مستخدم حقيقية بالمتصفح:
1. فتح صفحة الدخول على `http://127.0.0.1:3000` والتحقق من عدم وجود شاشة بيضاء وتهيئة CSRF.
2. تسجيل الدخول الحقيقي باستخدام بيانات حساب اختبار تُمرّر عبر متغيرات البيئة فقط:
   - `E2E_USERNAME` و `E2E_PASSWORD` (أو `VERIFY_USERNAME`/`VERIFY_PASSWORD` أو `PLATFORM_ADMIN_USERNAME`/`PLATFORM_ADMIN_PASSWORD`).
3. التحقق من عدم حدوث `401` بعد الدخول، وظهور القائمة الجانبية (`القائمة الرئيسية`)، والانتقال إلى شاشة **المشتريات** (و**الخزينة والعهد** عند توفر الصلاحية) والتحقق من ظهور عناصر الشاشة المتوقعة.

مثال التشغيل محلياً بعد تهيئة قاعدة بيانات `loopback` وحساب الاختبار:

```bash
E2E_USERNAME=admin E2E_PASSWORD='...' npm run test:e2e-smoke
```

- إذا كان `npm run dev` (أو خادم الإنتاج المبني على `:3000`) يعمل بالفعل، يعيد Playwright استخدامه (`reuseExistingServer: true`)؛ وإلا يشغّل `npm run dev` تلقائياً.
- لتحديد عنوان آخر: `E2E_BASE_URL=http://127.0.0.1:3000` (ويمكن تمرير `E2E_SKIP_WEBSERVER=1` عند الفحص ضد خادم خارجي جاهز).
