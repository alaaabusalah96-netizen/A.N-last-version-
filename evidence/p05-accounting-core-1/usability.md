# Usability & UI Visibility Assessment — AN-P05-ACCOUNTING-CORE-1

- **UI Navigation**: Authenticated users can toggle between "إدارة الشركات" and "المحاسبة" in the primary dashboard navigation bar.
- **Accounting Workspace**: Provides company selector dropdown, active tenant account list, and tab switching between "دليل الحسابات" and "دفتر اليومية".
- **Chart of Accounts Panel**:
  - Displays table of accounts (Code, Arabic Name, English Name, Type, Postable, Status).
  - Button "تحميل الدليل الافتراضي" seeds standard 11 Arabic/English accounts for empty companies.
  - Button "حساب جديد" opens a modal form allowing instant account creation with validation and error feedback.
- **RTL & Localization**: Fully localized in Arabic with clean dark-mode Tailwind UI matching existing foundation styling.
